# Contributing to ProDigital Consulting GmbH

Thank you for your interest.

This repository is used as the organization-level profile repository.

## Scope

This GitHub organization is operated as a private, proprietary environment.

- No public open-source repositories are maintained here.
- External code contributions via public pull requests are not accepted.
- Any collaboration requires explicit written agreement.

## Collaboration Requests

For project or partnership inquiries, contact us via https://www.pro-digital.de/.

## Internal Pull Requests

- Only for authorized internal team members or approved partners.
- Provide a clear rationale and testing details.
- Highlight risks and potential breaking changes.

## Reporting

- Security-related topics must not be disclosed publicly.
- Use direct contact channels listed on https://www.pro-digital.de/.

## Communication

- Be respectful and constructive.
- Keep feedback specific and actionable.
- Prefer clarity over volume.

## Security

Please do not create public issues for security vulnerabilities.

Contact us directly via the channels on https://www.pro-digital.de/ for responsible disclosure.
